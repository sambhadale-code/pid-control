# PID Control Resources

## Knowledge

- [Control Tutorials for MATLAB and Simulink: PID Control](https://ctms.engin.umich.edu/CTMS/index.php?example=Introduction&section=ControlPID)
  Excellent beginner-friendly explanation of the anatomy of a PID loop, tuning intuition, and step-response concepts. Use for: basic concept building and visual intuition.
- [Wikipedia: PID Controller](https://en.wikipedia.org/wiki/PID_controller)
  Concise but rigorous definition of the formula, error terms, and practical versions of the controller. Use for: checking the exact notation and terminology.
- [MIT OpenCourseWare: Feedback Systems](https://ocw.mit.edu/courses/2-010-system-modeling-analysis-and-control-ii-spring-2015/)
  Strong, mathematically grounded course material for understanding control systems beyond the basics. Use for: transfer functions, stability intuition, and the meaning of P, I, and D.
- [Ziegler-Nichols tuning method](https://en.wikipedia.org/wiki/Ziegler%E2%80%93Nichols_tuning_method)
  Standard tuning recipe used in the assignment. Use for: the second-system tuning exercise and comparing manual tuning to a documented method.

## Wisdom (Communities)

- [r/ControlTheory](https://www.reddit.com/r/ControlTheory/)
  Good place to ask practical questions about tuning and to benchmark intuition against experienced controls engineers. Use for: real-world debugging/examples beyond classroom exercises.
- Local university or maker lab controls group
  If available, use it for live feedback on tuning decisions and to practice explaining the controller under interview-like pressure.

## Gaps

- No single source perfectly matches the assignment’s exact graph-and-report requirements, so the implementation should be built from the fundamentals and kept reproducible in code.
