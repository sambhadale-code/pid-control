PID Control Quick Reference

Core equation

u(t) = Kp e(t) + Ki ∫e(t) dt + Kd de(t)/dt

where e(t) = setpoint - measurement.

Discrete-time version

e_k = r_k - y_k
I_k = I_{k-1} + e_k * dt
D_k = (e_k - e_{k-1}) / dt
u_k = Kp * e_k + Ki * I_k + Kd * D_k

What each term does

TermMeaningTypical effect
PCurrent errorFaster response, but can leave a residual offset
IAccumulated past errorRemoves steady-state error, but can overshoot
DRate of change of errorDamps oscillation and improves stability

Four performance measures

  • Rise time: time to go from 10% to 90% of the final value.
  • Overshoot: maximum amount above the target, expressed as a percentage.
  • Settling time: time until the response stays inside a small threshold band.
  • Steady-state error: final offset from the target.

Common tuning intuition

  • Raise Kp to get to the target faster.
  • Raise Ki to eliminate offset, but watch for windup.
  • Raise Kd to suppress bounce, but do not let it amplify noise.

Ziegler–Nichols quick recipe

Raise Kp until the loop oscillates steadily.
Note the critical gain Ku and oscillation period Pu.

P: Kp = 0.5 Ku
PI: Kp = 0.45 Ku, Ki = 1.2 Kp / Pu
PID: Kp = 0.6 Ku, Ki = 2 Kp / Pu, Kd = Kp * Pu / 8

Practical fixes

  • Use integral clamping to avoid windup.
  • Filter or limit derivative action when sensor noise is present.
  • Compute D on measurement instead of error to reduce setpoint kick.
  • Choose a sample time that is fast enough for the system dynamics.
