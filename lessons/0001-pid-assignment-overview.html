Lesson 1

PID control: how to read this assignment and build the solution

Reference Resources Glossary

The assignment is not asking for magic. It is asking for a clean story: what the controller is doing, why the math makes sense, and how the graph changes when the gains change. That is exactly what PID control is: a feedback loop that keeps reducing the error between the target and the current value.

A good mental model is a shower: you turn the hot/cold knobs until the water temperature matches the target. PID does the same thing automatically, but for machines.

1. The basic idea

At each moment, the controller measures the current value, compares it to the target, and decides how much force or command to apply next. The error is:

error = setpoint - measured_value

Then the controller combines three signals:

  • P: reacts to the current error.
  • I: remembers past error and removes a persistent offset.
  • D: reacts to how fast the error is changing and reduces oscillation.
u(t) = Kp e(t) + Ki ∫e(t) dt + Kd de(t)/dt

2. What the assignment is really asking

The document must teach the 10 required sections, but the hidden goal is to show understanding rather than memorization.

  1. Explain the loop clearly.
  2. Derive and interpret the PID formula.
  3. Model the 1 kg spring-damper plant.
  4. Measure performance with standard metrics.
  5. Show how P alone behaves, then add I and D.
  6. Compare P, PI, PD, and full PID.
  7. Diagnose real-world problems and fixes.
  8. Explain tuning by hand and with Ziegler–Nichols.
  9. Implement the controller in Python with the fixes.
  10. Connect the result to real robots and common myths.

3. The physical system you will simulate

The reference system is a 1 kg mass attached to a spring and damper:

m x'' + c x' + k x = F

with m = 1 kg, c = 10 N·s/m, and k = 20 N/m. The controller pushes on the mass until the position reaches 1 m. The spring naturally resists motion, so a constant force is needed to hold the mass at a nonzero position.

4. What to implement in code

A good project structure is:

  • simulate the plant
  • implement PID with anti-windup and derivative filtering
  • extract performance metrics
  • generate the graphs for each section

Use NumPy for the numerical integration and Matplotlib for all plots. Every figure should include a clear title, axis labels with units, a legend, and one sentence explaining what it shows.

5. The inside of the controller

u = Kp * e + Ki * integral + Kd * derivative

The main idea is simple: the controller produces a command u from error. It tries to drive the error toward zero. The challenge is choosing gains that are fast enough without becoming unstable, noisy, or saturated.

6. Why this matters in the interview

The interview is likely to change one parameter and ask you to predict the outcome before running the code. That means you need intuition, not just a script. Practice this mental checklist:

  • more Kp -> faster response, more overshoot
  • more Ki -> removes offset, can wind up
  • more Kd -> more damping, more noise sensitivity
  • slower timestep -> more lag and worse control
Important: for the assignment, do not just say “higher Kp is better.” Say exactly what happens to rise time, overshoot, and settling time, and tie it back to the graph you generated.

7. Recommended primary source

The best starting reference is the Control Tutorials for MATLAB and Simulink: PID Control. It matches the assignment’s teaching style and gives the clearest beginner-friendly explanation.

Ask follow-up questions to the agent any time a graph, formula, or tuning result feels fuzzy. The aim is to make the assignment feel intuitive, not intimidating.
